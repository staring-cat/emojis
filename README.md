# Cat Bot emojis
### The emojis for cat bot
#### [Download latest zip](https://github.com/staring-cat/emojis/releases/latest/download/emojis.zip)

## Structure

- `base/` - everything that isn't a cat-catching spawn emoji (packs, badges, achievements, rarity icons, etc.)
- `spawning/` - cat-catching emojis, one folder per theme (`default`, `birthday`, `halloween`, `old`, `fish`)

Note: custom cats folder is deprecated and won't be updated.
